# React + TypeScript + Vite

The Wails frontend for Icon Foundry is built with React, TypeScript, and Vite.

## Commands

- `npm run dev` starts the Vite development server used by Wails.
- `npm run check` type-checks the application and Vite configuration.
- `npm test` runs the dependency-light utility tests.
- `npm run build` writes the production frontend to `dist` for Wails embedding.
